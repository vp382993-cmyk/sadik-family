# SADIK FAMILY — Общая онлайн-версия v3

Это версия для одного общего сайта: все участники заходят по одной публичной ссылке и работают с одной PostgreSQL базой.

## Самый простой вариант — Render
1. Создай аккаунт на Render.
2. Создай GitHub-репозиторий и загрузи в него содержимое этой папки.
3. В Render выбери **New → Blueprint** и укажи репозиторий.
4. Render создаст Web Service и PostgreSQL по `render.yaml`.
5. После деплоя появится адрес вида `https://sadik-family-....onrender.com`.
6. Эту одну ссылку можно дать всем участникам.
7. Первый вход: admin / admin123. Сразу поменяй пароль через админку.

ВАЖНО:
- Бесплатный Render Postgres подходит для теста, но по текущей документации Render бесплатные Postgres-базы истекают через 30 дней. Для постоянной семейной системы нужен платный datastore/другая постоянная БД.
- Не публикуй `DATABASE_URL` или `SESSION_SECRET`.
- Приложение слушает `0.0.0.0` и использует переменную `PORT`, как требуется для Render.

## Локально
Нужен PostgreSQL и `DATABASE_URL`. Затем:
npm install
npm start
